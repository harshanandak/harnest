Use the `harnest:handoff` skill. Build a complete background request with an explicit request ID from `$ARGUMENTS`; name the target (or `auto`) and let policy choose; set `route.model` only when the user names a model. Amp uses prompt-only attached one-shot execution, rejects `execution.transport=session` and live controls, and resumes follow-ups with `execution.sessionId`. Amp requires explicit write policy with approval, empty tools, null `maxCostUsd`, and native Linux/macOS or the entire MCP server running inside WSL; native Windows rejects before inference, and generated settings reduce risk but are not containment. Generic ACP selects an explicitly trusted local registration with `route.agent`; it is write-only and requires `policy.write=true` plus `metadata.harnest.writeApproved=true`. It rejects `execution.transport=session` and live controls, while later follow-ups resume or load the negotiated native session through `execution.sessionId`. DeepSeek models run via Pi or OpenCode provider routes — there is no DSH downstream target. Call `handoff_workflow` once, follow status to terminal, and present the full compact receipt without condensing it. Recover by request ID if the initial response is lost.
