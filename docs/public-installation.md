# Harnest MCP installation

Start with the [user documentation](users/README.md) and [getting started guide](users/getting-started.md). User guides cover setup and operation; internal plans and validation records are kept separately and excluded from public release snapshots.

Gemini, Amp, and generic ACP support native-session follow-up and reject session transport and live controls. Generic ACP requires an explicitly trusted local registration and approved write-capable work; native installation and authentication remain with the operator.
